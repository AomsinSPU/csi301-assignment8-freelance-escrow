# CSI301 Assignment 8 · Freelance Escrow

เว็บแอปพลิเคชันสำหรับพักค่าจ้างฟรีแลนซ์ด้วยสัญญาอัจฉริยะบนเครือข่ายทดสอบ Ethereum Sepolia ผู้ว่าจ้างฝากค่าจ้างไว้ในสัญญาและอนุมัติจ่ายหลังตรวจรับงาน หากเกิดข้อพิพาท คู่สัญญาสามารถส่งหลักฐานให้ผู้ตัดสินพิจารณาว่าจะจ่ายค่าจ้างให้ฟรีแลนซ์หรือคืนเงินให้ผู้ว่าจ้าง

## วิธีทดลองใช้งาน

1. เปิดเว็บ เชื่อม MetaMask แล้วเลือกเครือข่าย Sepolia ใช้ ETH ทดสอบสำหรับค่าจ้างและค่าธรรมเนียมธุรกรรม
2. ผู้ว่าจ้างสร้างข้อตกลง ระบุบัญชีฟรีแลนซ์ ค่าจ้าง และกำหนดส่ง จากนั้นฝากค่าจ้างตามยอดที่ตกลง
3. ฟรีแลนซ์ส่งหลักฐานการทำงานผ่านหน้ารายละเอียดงาน จากนั้นผู้ว่าจ้างตรวจรับและอนุมัติจ่าย
4. หากเข้าเงื่อนไขข้อพิพาท คู่สัญญาสามารถเปิดข้อพิพาทและส่งหลักฐานผ่านเว็บ ผู้ตัดสินจึงเลือกจ่ายค่าจ้างหรือคืนเงินตามเงื่อนไขในสัญญา

หน้ารายละเอียดงานแสดงสถานะและประวัติธุรกรรมพร้อมลิงก์ให้ตรวจสอบบน Sepolia Etherscan

## เทคโนโลยี

- **Solidity** สำหรับสัญญาพักค่าจ้างและจัดการข้อพิพาท
- **React, TypeScript และ Vite** สำหรับหน้าเว็บ
- **ethers.js และ Tenderly Sepolia RPC** สำหรับอ่านสถานะสัญญาและประวัติธุรกรรม
- **MetaMask** สำหรับยืนยันและลงนามธุรกรรม
- **GitHub Pages** สำหรับเผยแพร่เว็บ
